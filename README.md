# Däckhotell — visningsdemo

Publik, klickbar prototyp av däckhotell-systemet, brandad för Woxnadalens Bilservice i Alfta.

**Live:** https://andersabjorn.github.io/dackhotell-demo/#registrera

All kunddata i demon är påhittad (fejkade regnr och 070-000-nummer). Sidan är märkt `noindex`. Detta är inte produktionskod och inte det privata produktrepot.

QR-koden på registreringssidan pekar på den här adressen.
